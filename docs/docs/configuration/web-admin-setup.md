# Web Admin 初始化

首次启动机器草后，需要通过 Web Admin 完成基础配置。

## 1. 创建管理员账户

访问 `http://<主机>:8081/setup`，设置管理员用户名与密码。此步骤仅在数据库中尚无管理员时可用。

## 2. 登录

完成初始化后，通过 `/login` 登录管理面板。

## 3. 连接 OneBot 协议端

OneBot **不在** Web Admin 面板里填写地址。请将协议端（如 NapCat、LLOneBot）配置为反向 WebSocket，连接到机器人监听端口（默认 **8080**，由环境变量 `HOST`/`PORT` 决定，见 [环境变量](./env-vars)）。

在 **设置 → 机器人** 中配置的是 **超级用户** 与状态查询专用白名单等权限项。

## 4. 配置 B 站账号

在 **设置 → B 站账号** 中登录或填写 Cookie。配置 B 站账号可提高 API 请求成功率，对动态截图、直播监控等功能尤为重要。

支持扫码登录，Cookie 加密存储在数据库中。

## 5. （可选）配置抖音账号

若需 [抖音链接解析](../plugins/douyin-link-parser)，在 **设置 → 抖音账号** 中扫码登录或粘贴 Cookie（与 B 站账号相互独立）。未配置时仍会尝试游客态解析，登录态更稳。

## 6. 添加监控映射

根据需求在对应页面添加监控：

- **直播监控**（`/live`）：房间号 → 目标群/好友
- **动态监控**（`/dynamic`）：UP 主 UID → 目标群/好友（动态推送与视频查询命令共用此映射）

## 7. 配置权限策略

在 **群组**（`/groups`）和 **好友**（`/private`）页面中：

- 开关群/好友消息响应（守卫）
- 配置 B 站链接解析策略
- 配置抖音链接解析开关（默认关闭，需按会话开启）
- 配置状态查询允许名单与回复内容
- （仅群组）配置 [群头衔](../plugins/group-special-title) 白名单与每日次数

## 8. 自定义消息模板与命令

- **消息模板**：各平台侧栏下的「消息模板」（如 `/templates/bilibili`、`/templates/x`、`/templates/douyin`）
- **设置 → 命令**：核心命令触发词与习惯性前缀（Rust 群管命令在 `/rust-rcon`）

## 9. （可选）配置 Rust 群管

若需通过 QQ 管理 Rust 服务器或群内签到/商城，打开 **Rust 群管**（`/rust-rcon`）：

1. **服务器绑定**：填写 WebRCON 地址、端口、密码、触发词与允许执行的 QQ
2. **群权限 / 好友权限**：对目标会话开启 **Rust 远控**（默认关闭；须已开启消息守卫）
3. 按需配置 **群管命令**、**积分与绑定**、**积分商城**

详见 [Rust RCON 远控](../plugins/rust-rcon)、[Rust 群积分与商城](../plugins/rust-player)。Rust 相关配置无专用环境变量，均存数据库。
