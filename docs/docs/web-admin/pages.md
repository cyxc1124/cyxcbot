# 页面说明

侧栏按平台 / 能力分组：**概览**、**B 站**、**X**、**抖音**、**会话**、**游戏**、**系统**。

## 仪表盘 `/`

运行概览，包括：

- OneBot / 官方 Bot / B 站相关连接状态（以协议端、官方凭证与 Cookie 是否可用为准）
- **监控统计**：动态 / 直播 / X 目标数量与检查概况
- **资源**：进程与系统 CPU、内存等；数据库与日志目录体积（若可用）

不在此页配置业务；用于快速确认机器人是否在跑。

## 动态订阅 `/bilibili/dynamic`

侧栏 **B 站 → 动态订阅**。

- 查看各 UP 主状态与最近检查时间
- 添加/编辑/删除 UID 与目标群/好友映射
- 监控模式（分散 / 批量）由 **B 站 → 订阅参数** 控制
- **立即检查**：手动触发一轮动态检查

另支持新动态推送与**置顶动态变更推送**；主动查询命令见 [动态监控](../plugins/dynamic-monitor)。

## 直播订阅 `/bilibili/live`

侧栏 **B 站 → 直播订阅**。

- 查看各直播间状态（开播/下播、WebSocket 等）
- 添加/编辑/删除房间号与目标群/好友映射
- 配置 @全体 等推送选项
- **立即检查**：手动触发一轮直播检查（不等待轮询周期）

## 推文订阅 `/x/subscriptions`

侧栏 **X → 推文订阅**。

- 查看各博主状态与最近检查时间
- 添加/编辑/删除 username 与目标群/好友映射
- 检查间隔由 **X → 订阅参数** 控制
- **立即检查**：手动触发一轮推文检查

详见 [X 推文监控](../plugins/x-monitor)。

## 链接解析

各平台的「链接解析」（`/bilibili/parser`、`/x/parser`、`/douyin/parser`）统一提供群组 / 好友两种视角，与会话页复用同一策略编辑器。群消息、好友消息守卫和解析分项仍按原规则生效，关闭入站消息不影响主动订阅推送。账号、模板与共享媒体目录可从解析页直接进入。

## 群组 `/groups`

侧栏 **会话 → 群组**。可用 `?tab=status` 直达状态查询权限，标签状态随网址保存。

官方 Bot 在收到群事件后会显示带「官方」标记的 OpenID。即使没有 OneBot 在线，也可在「群消息」中开启已发现的官方群；列表不完整时，仅允许在白名单模式下单独修改这些会话，批量操作和 OneBot 会话保持只读。

未接入 OneBot 时显示官方会话的正常发现说明，不提示同步失败。只有已连接的 OneBot 群列表获取失败时才显示警告；官方缓存不被当成完整 OneBot 名单。

| Tab | 说明 |
|-----|------|
| 群消息 | 群消息守卫（是否处理入站群消息） |
| 状态查询 | 按群允许名单；**状态回复内容**（详细技术信息 / 运行时长 / 内存） |
| 群头衔 | 白名单启用群；每人每日设置次数上限。见 [群头衔设置](../plugins/group-special-title) |
| B 站链接 | B 站链接解析策略（视频 / 直播 / 动态等分项） |
| 抖音链接 | 抖音链接解析开关（默认关闭） |
| X 链接 | X 链接解析开关（默认关闭） |

## 好友 `/friends`

侧栏 **会话 → 好友**。同样支持 `?tab=status` 等标签直达。

官方 Bot 收到 C2C 私聊后会显示带「官方」标记的用户。若日志提示「未启用好友消息」，刷新本页，在「好友消息」中打开该用户的「处理好友消息」，再发送私聊。列表不完整时，单独修改官方会话会保留其他允许名单，不会自动切换为全部启用。

未接入 OneBot 时不会显示「好友列表获取失败」警告；官方好友按私聊事件逐步发现。在全部启用模式下，页面说明官方消息已允许处理。

| Tab | 说明 |
|-----|------|
| 好友消息 | 私聊守卫 |
| 状态查询 | 按好友允许名单与回复内容开关 |
| B 站链接 | B 站链接解析策略 |
| 抖音链接 | 抖音链接解析开关（默认关闭） |
| X 链接 | X 链接解析开关（默认关闭） |

## 消息模板

各平台侧栏下的 **消息模板**，按「订阅推送」「命令回复」「链接解析」分组；动态图片提取的成功、无图、失败与单图标签放在该功能的子列表内：

| 路径 | 侧栏 | 内容 |
|------|------|------|
| `/bilibili/templates` | B 站 → 消息模板 | 动态 / 直播推送与查询、B 站视频·直播链接解析 |
| `/x/templates` | X → 消息模板 | 新推文推送、X 链接解析 |
| `/douyin/templates` | 抖音 → 消息模板 | 抖音链接解析 |

Rust 群管回复为插件内置文案，不在此页。模板仍按单项保存，切换有未保存草稿的模板时继续提示确认。

## Rust 管理

从「游戏 → Rust 管理」进入，按「远控与权限」「玩家与积分」折叠分层，每项功能有独立网址。须先开启消息守卫，再开启 **Rust 远控**（默认关闭）。拆分页面不会放宽原有的 RCON、会话和允许执行 QQ 权限。详见 [Rust RCON 远控](../plugins/rust-rcon)、[Rust 群积分与商城](../plugins/rust-player)。

| 分组 | 路径 | 说明 |
|------|------|------|
| 远控与权限 | `/rust/remote/servers` | 服务器连接、触发词、密码与允许执行 QQ |
| 远控与权限 | `/rust/remote/groups`、`/rust/remote/friends` | 群 / 好友 RCON 总开关 |
| 远控与权限 | `/rust/remote/commands` | 群管命令触发词 |
| 远控与权限 | `/rust/remote/custom` | 自定义远控指令 |
| 玩家与积分 | `/rust/players/accounts` | 签到区间、在线加成、首次绑定奖励、SteamID 与积分 |
| 玩家与积分 | `/rust/players/shop` | 积分商城商品 |

## 平台设置与系统配置

账号和订阅参数直接归各平台；系统分组只保留机器人接入、全局权限、通用命令、高级配置、日志和关于。

### B 站 → 订阅参数 `/bilibili/settings`

| 项 | 说明 |
|----|------|
| 动态检查间隔 | 期望每个 UP 主约每 N 秒检查一次（有上下限） |
| 启用分散检查 | 推荐；目标多时分散请求，单次间隔不低于约 3 秒。关闭则周期性依次检查全部 |
| 动态截图 | Playwright 网页截图 |
| API 请求频率预估 | 根据间隔与目标数估算请求节奏（动态 / 直播各一卡片） |
| 直播检查间隔 | WebSocket 开启时主要影响 API 备用轮询 |
| 通知包含详细房间信息 | 开播通知是否附带更详细房间字段 |
| 启用 WebSocket 实时监控 | 弹幕 WebSocket + API 备用 |

### X → 订阅参数 `/x/settings`

| 项 | 说明 |
|----|------|
| 检查间隔 | 期望每个博主约每 N 秒检查一次 |
| 启用分散检查 | 推荐；目标多时分散请求 |
| API 请求频率预估 | 根据间隔与目标数估算请求节奏 |

### B 站 / 抖音 / X 账号

- **B 站 → 账号**：扫码或粘贴 Cookie
- **抖音 → 账号**：扫码或粘贴 Cookie（与 B 站相互独立）
- **X → 账号与代理**：Bearer Token 与出站代理（监控与链接解析共用）

### 系统 → 命令 `/system/commands`

自定义**非 Rust** 核心命令的触发词与开关（保存立即生效）。Rust 群管命令请到 `/rust/remote/commands`。

| 命令（面板标签） | 默认触发词（示例） |
|------------------|-------------------|
| 运行状态查询 | `status`、`状态`、`运行状态` |
| 直播状态查询 | `直播状态`、`查直播`、`live` |
| 直播监控列表 | `监控列表`、`直播监控列表` |
| 最新动态查询 | `最新动态` |
| 置顶动态查询 | `置顶动态` |
| 最新投稿查询 | `最新视频`、`最新投稿` |
| 动态图片提取 | `提取`、`获取`（**必须带前缀**） |
| 群头衔设置 | `头衔`（**必须带前缀**） |

**前缀：**

- `COMMAND_START`（环境变量，默认 `/`，改需重启）
- **习惯性前缀**（默认 `!` `。` `.` `#`，可在此页改，立即生效；可留空）

除「动态图片提取」「群头衔设置」外，其余命令还支持裸触发词或 `@机器人` + 触发词。保存触发词或习惯性前缀时，会按保存后的完整前缀集合检查启用命令的冲突；例如 `/` 生效时，两个支持裸触发的启用命令分别使用 `status` 与 `/status` 会被拒绝。禁用命令保留的触发词不参与冲突检查。

### 系统 → 机器人接入 `/system/connections`

- **AppID / AppSecret**：QQ 开放平台凭证，加密存库，保存后立即生效
- **连接方式**：默认使用 Webhook；旧版 WebSocket 默认关闭，仅为仍可使用旧链路的应用保留。官方 QQ 已统一 API，测试成员和测试群在开放平台配置，不再提供沙箱开关
- **Webhook 回调**：公网 HTTPS `/qq/webhook` 转发到机器人端口（默认 8080），在开放平台完成验证、订阅事件并配置出口 IP 白名单。详见 [接入配置](../configuration/web-admin-setup)
- **能力范围**：官方群聊/C2C 支持命令和链接解析回复，动态、直播和 X 监控也可配置官方目标；主动投递受 QQ 平台策略限制，终止拒绝不会无限重试。X 的链接解析支持图片/视频，按官方群五次、C2C 四次被动回复安排文案及媒体，超出部分明确提示查看原推文
- **直播恢复**：通知消息快照、失败目标与分段进度持久化，监控重建后续传；官方 `@全体` 使用文字提示。被动回复仍受每条用户消息官方群最多 5 次、C2C 最多 4 次的限制

**不在此页配置 OneBot 连接**。官方 Bot 与 OneBot 双栈并行。

### 系统 → 权限 `/system/permissions`

- **NoneBot 超级用户**：QQ 号或官方用户 openid；默认可查状态等，保存后同步到运行中机器人
- **状态查询专用白名单**：允许非超级用户在任意会话触发 `/status`（更细的按群/好友开关在群组/好友 → 状态查询）

**不在此页配置 OneBot 连接**：协议端请反向 WebSocket 连机器人监听端口（默认 **8080**，见 [环境变量](../configuration/env-vars) 的 `HOST`/`PORT`）。

### 系统 → 高级配置 `/system/advanced`

链接解析共享媒体目录单独保存，不与超级用户或状态查询授权一起提交。留空恢复平台默认路径；分离部署时仍需让机器草与协议端共享同一路径。

## 日志 `/logs`

实时查看机器人运行日志（SSE 推送，无需刷新页面）。

| 能力 | 说明 |
|------|------|
| 输出级别设置 | 位于工具栏「显示选项」内，以单选胶囊分别设置终端、文件级别，保存后立即生效并持久化，无需重启；支持 TRACE 至 CRITICAL，保存值优先于环境变量 |
| Web 显示级别 | 多选 DEBUG、INFO、SUCCESS、WARNING、ERROR、CRITICAL（**默认 INFO 及以上**）；只筛选当前页面，与终端和文件输出独立 |
| 搜索与导出 | 按消息、模块、级别或时间搜索；导出当前筛选和行数范围内的完整日志为 UTF-8 `.log`，含多行消息和未滚动到的行 |
| 视图预设 | 开发（2000 行、全部可用级别）、运维（默认；1000 行、INFO 及以上）、精简（500 行、WARNING 及以上）；可单独调整行数与自动换行 |
| 历史缓冲 | 服务端 `INFO`+、`DEBUG` 分别最多 2000 条；页面加载和展示最多 2000 条 |
| 重连与暂停 | 断线后每 3 秒重连并回放缓存、去重；暂停显示期间继续接收，待显示缓冲最多 2000 条 |
| 与终端差异 | 缓冲含 `DEBUG`，但默认筛选为 `INFO`；要看 `DEBUG` 需手动改级别。入站事件 dump 与 Matcher 调度行仅终端 / 磁盘有 |
| 持久化 | **不**替代磁盘日志；重启后缓冲清空 |

排障、跨天查日志请使用 `data/logs/` 下文件或容器 `docker compose logs`。详见 [日志配置](../configuration/logging)。
