# 页面说明

## 仪表盘 `/`

运行概览，包括：

- OneBot / B 站相关连接状态（以协议端与 Cookie 是否可用为准）
- **监控统计**：动态 / 直播目标数量与检查概况
- **资源**：进程与系统 CPU、内存等；数据库与日志目录体积（若可用）

不在此页配置业务；用于快速确认机器人是否在跑。

## 直播监控 `/live`

- 查看各直播间状态（开播/下播、WebSocket 等）
- 添加/编辑/删除房间号与目标群/好友映射
- 配置 @全体 等推送选项
- **立即检查**：手动触发一轮直播检查（不等待轮询周期）

## 动态监控 `/dynamic`

- 查看各 UP 主状态与最近检查时间
- 添加/编辑/删除 UID 与目标群/好友映射
- 监控模式（分散 / 批量）由 **设置 → 监控参数** 控制
- **立即检查**：手动触发一轮动态检查

另支持新动态推送与**置顶动态变更推送**；主动查询命令见 [动态监控](../plugins/dynamic-monitor)。

## 群组 `/groups`

| Tab | 说明 |
|-----|------|
| 群消息 | 群消息守卫（是否处理入站群消息） |
| 群链接解析 | B 站链接解析策略（视频 / 直播 / 动态等分项） |
| 抖音链接 | 抖音链接解析开关（默认关闭） |
| 状态查询 | 按群允许名单；**状态回复内容**（详细技术信息 / 运行时长 / 内存） |
| 群头衔 | 白名单启用群；每人每日设置次数上限。见 [群头衔设置](../plugins/group-special-title) |

## 好友 `/private`

| Tab | 说明 |
|-----|------|
| 好友消息 | 私聊守卫 |
| 好友链接解析 | B 站链接解析策略 |
| 抖音链接 | 抖音链接解析开关（默认关闭） |
| 状态查询 | 按好友允许名单与回复内容开关 |

## 消息模板 `/templates`

自定义推送文案（变量占位符），主要包括：

- 动态：推送、**置顶变更**、最新/置顶查询、图片提取（含空/失败文案）
- 直播：开播 / 下播
- B 站链接：视频、直播（动态 / opus 链接复用视频模板）
- 抖音链接：`link_template_douyin`

Rust 群管回复为插件内置文案，不在此页。

## Rust 群管 `/rust-rcon`

侧栏 **Rust 群管**，标题 **Rust 远控管理**。须先开启消息守卫，再开启 **Rust 远控**（默认关闭）。详见 [Rust RCON 远控](../plugins/rust-rcon)、[Rust 群积分与商城](../plugins/rust-player)。

| Tab | 说明 |
|-----|------|
| 服务器绑定 | WebRCON 触发词、地址、端口、密码、允许执行的 QQ、启用 |
| 群权限 / 好友权限 | 按会话开关 Rust 远控 |
| 群管命令 | 绑定、签到、积分、商品列表、兑换触发词（与设置 → 命令分离） |
| 积分与绑定 | 签到区间、在线加成、首次绑定奖励、RCON 服务器；积分与 SteamID |
| 积分商城 | 商品 CRUD |

## 设置 `/settings`

### 监控参数

| 项 | 说明 |
|----|------|
| 动态检查间隔 | 期望每个 UP 主约每 N 秒检查一次（有上下限） |
| 启用分散检查 | 推荐；目标多时分散请求，单次间隔不低于约 3 秒。关闭则周期性依次检查全部 |
| 动态截图 | Playwright 网页截图 |
| API 请求频率预估 | 根据间隔与目标数估算请求节奏（动态 / 直播各一卡片） |
| 直播检查间隔 | WebSocket 开启时主要影响 API 备用轮询 |
| 通知包含详细房间信息 | 开播通知是否附带更详细房间字段 |
| 启用 WebSocket 实时监控 | 弹幕 WebSocket + API 备用 |

### B 站账号 / 抖音账号

扫码或粘贴 Cookie；二者相互独立。

### 命令

自定义**非 Rust** 核心命令的触发词与开关（保存立即生效）。Rust 群管命令请到 `/rust-rcon` → 群管命令。

| 命令（面板标签） | 默认触发词（示例） |
|------------------|-------------------|
| 运行状态查询 | `status`、`状态`、`运行状态` |
| 直播状态查询 | `直播状态`、`查直播`、`live` |
| 直播监控列表 | `监控列表`、`直播监控列表` |
| 最新动态查询 | `最新动态` |
| 置顶动态查询 | `置顶动态` |
| 最新投稿查询 | `最新视频`、`最新投稿` |
| 动态图片提取 | `提取`、`获取`（**必须带前缀**） |
| 群头衔设置 | `头衔`（**必须带前缀**） |

**前缀：**

- `COMMAND_START`（环境变量，默认 `/`，改需重启）
- **习惯性前缀**（默认 `!` `。` `.` `#`，可在此页改，立即生效；可留空）

除「动态图片提取」「群头衔设置」外，其余命令还支持裸触发词或 `@机器人` + 触发词。

### 机器人

- **NoneBot 超级用户**：QQ 号列表；默认可查状态等，保存后同步到运行中机器人
- **状态查询专用白名单**：允许非超级用户在任意会话触发 `/status`（更细的按群/好友开关在群组/好友 → 状态查询）

**不在此页配置 OneBot 连接**：协议端请反向 WebSocket 连机器人监听端口（默认 **8080**，见 [环境变量](../configuration/env-vars) 的 `HOST`/`PORT`）。

## 日志 `/logs`

实时查看机器人运行日志（WebSocket 推送，无需刷新页面）。

| 能力 | 说明 |
|------|------|
| 级别筛选 | `DEBUG` / `INFO` / `WARNING` / `ERROR`（**默认 `INFO`**） |
| 历史缓冲 | 服务端内存约 2000 条（`DEBUG`+）；打开页面先拉约 500 条 |
| 与终端差异 | 缓冲含 `DEBUG`，但默认筛选为 `INFO`；要看 `DEBUG` 需手动改级别 |
| 持久化 | **不**替代磁盘日志；重启后缓冲清空 |

排障、跨天查日志请使用 `data/logs/` 下文件或容器 `docker compose logs`。详见 [日志配置](../configuration/logging)。
