# 群消息守卫

控制机器人是否处理某个群的入站消息（命令、链接解析等），同时作用于 OneBot 群和官方 QQ 群。

## 配置

在 **Web Admin → 会话 → 群组** 的「群消息」标签中，逐个打开「处理群消息」。

- **默认只处理已开启的群**：新部署时所有群都未开启，需要逐个打开。
- 打开列表中的全部群后，切换为「全部启用」，之后新加入的群也会直接处理；在全部启用时关闭任意一个群，会回到只处理已开启群的模式。
- 关闭后，机器人在该群中不处理任何命令与插件逻辑。

## 官方 QQ 群

官方群在机器人收到该群的消息事件（如被 @）后出现在列表中，显示带「官方」标记的 OpenID。未开启时，机器人忽略该群消息，并在日志中提示「官方群 … 未启用群消息，已忽略」；在群组页打开后再 @ 机器人即可。没有 OneBot 在线时，也可以单独开启已发现的官方群。

## 使用场景

- 在不需要机器人参与的群中静默
- 临时停用某群的所有功能而不删除监控映射
- 配合链接解析、状态查询、[群头衔](./group-special-title)、[Rust 群管](./rust-rcon) 等细粒度策略使用（守卫关闭时上述入站功能均不可用）

## 注意事项

关闭群消息处理后，该群中的监控推送**不受影响**（推送是机器人主动发送，不依赖入站消息）。
