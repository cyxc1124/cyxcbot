# Rust RCON 远控

通过 QQ 向 Rust 游戏服务器发送 [WebRCON](https://github.com/Facepunch/webrcon) 指令。对应插件：`rust_rcon`。

群内签到、SteamID 绑定与积分商城见 [Rust 群积分与商城](./rust-player)（共用「Rust 远控」总开关）。

## 前置条件

须同时满足：

1. 对应群 / 好友已开启**消息守卫**（见 [页面说明](../web-admin/pages) 中的群组 / 好友）
2. **Web Admin → Rust 群管 → 群权限 / 好友权限** 中开启 **Rust 远控**（默认关闭；未开启时静默忽略）
3. 已配置**服务器绑定**，且发送者 QQ 在该绑定的「允许执行的 QQ 号」列表中（不在白名单时静默忽略）

## 使用方法

| 场景 | 格式 | 示例 |
|------|------|------|
| 群聊 | `@机器人 触发词 命令` | `@机器人 rcon1 status` |
| 私聊 | `触发词 命令`（无需 @） | `rcon1 status` |

仅触发词、无后续命令时，机器人会提示补全命令（如 `{触发词} status`）。

协议为 Rust **WebRCON**（WebSocket），默认端口 **28016**。成功时回复 `[显示名称或触发词]` 与 RCON 输出；输出过长会截断。

## 配置

全部在 **Web Admin → Rust 群管**（路由 `/rust-rcon`），无专用环境变量。

### 服务器绑定

为每台服务器添加一条绑定：

| 字段 | 说明 |
|------|------|
| 触发词 | 匹配用别名（如 `rcon1`），勿与群管命令触发词冲突 |
| 显示名称 | 可选，用于回复前缀 |
| 服务器地址 / 端口 | WebRCON 地址，默认端口 28016 |
| 远控密码 | RCON 密码 |
| 允许执行的 QQ 号 | 白名单；仅约束本插件的任意 RCON 命令 |
| 启用 | 可关闭绑定而保留配置 |

### 群权限 / 好友权限

按群或好友开关 **Rust 远控**；支持全部启用、全部关闭、恢复默认。策略列表仅展示已开启消息守卫的会话。

## 注意事项

- 认证失败会提示检查 Web Admin 中的密码配置
- 触发词与 [Rust 群管命令](./rust-player)、其它命令别名冲突时，保存时会校验；启动日志也可能 warning
- 签到 / 商城兑换**不受**绑定级 QQ 白名单限制，但仍须开启 Rust 远控总开关
- 无 QQ 环境可用仓库脚本 `scripts/rust_rcon_probe.py` 探测绑定与 `giveto` 链路
