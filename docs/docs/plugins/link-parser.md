# B 站链接解析

自动识别群聊/好友中的 **B 站** 链接并回复解析结果。对应插件：`bilibili_link_parser`。

其它平台见 [抖音链接解析](./douyin-link-parser)、[X 链接解析](./x-link-parser)。

## 触发方式

无需命令，发送含以下内容的普通消息即可触发：

- BV 号视频链接
- 直播间链接
- `b23.tv` 短链
- B 站 QQ 小程序分享

OneBot V11 的群聊/好友消息和官方 QQ Bot 的官方群/C2C 均支持。官方群需 @ 机器人，C2C 直接发送；小程序分享只在适配器实际提供 JSON/XML 消息段时提取。

## 回复内容

根据链接类型返回：

- **视频**：封面、标题、UP 主、发布时间、链接
- **直播**：封面、主播名、直播状态、链接
- **动态**：封面（首图）、作者、发布时间、链接（`opus` / `t.bilibili.com`）

## 多 P 视频选择

单 P 视频直接返回解析结果；多 P 视频未指定分 P 时，会先展示目录：

```text
《视频标题》共 3 P：

P1 开场
P2 正式内容
P3 问答

请在 5 分钟内回复 1～3 之间的数字，选择分 P。
```

原用户在原群聊或私聊中回复 `2`，机器人就会解析第 2 P，文案显示 `P2 正式内容`，返回的链接也指向该 P。开启该会话的「发送视频」时下载并发送对应分 P；关闭时仍可选择，但只返回封面和文案。**官方 QQ 群需要 @ 机器人后回复数字**，官方 C2C 和 OneBot 私聊直接回复数字即可。

- BV/AV 视频链接已带 `?p=2` 等参数时直接处理指定 P，跳过目录。短链和小程序分享以展开后链接实际携带的参数为准；不携带分 P 信息时展示目录。
- 目录最多展示前 10 P，仍可回复有效范围内未展开的序号。
- 选择仅对原用户、原会话和原机器人有效，从目录确认发送成功开始计时，5 分钟后失效。收到合法数字时立即绑定所选 P 并清除待选记录，再排队处理；截止前已接收的选择不会因等待会话锁或下载名额而过期。
- 同一用户在同一会话内的解析与发送按顺序处理，新视频链接替换尚未消费的待选记录，即使新视频只有一 P 或详情获取失败，旧请求也不会恢复原选择。新目录不会覆盖或被之前已接收的选择消费。
- 越界数字会提示有效范围，不延长原来的有效期，可在截止前重新选择；非纯数字消息不作为分 P 选择处理。没有待选视频或记录已过期时，普通数字消息不会触发解析。
- 每次选择重新检查当前会话的解析权限。非法或越界的 `p` 参数会提示有效范围，不会悄悄返回第一 P。
- 后台统一任务每 30 秒清理过期待选记录，查询和新增时也会清理；有效性按接收数字时的 300 秒截止时间判断，不因清理间隔延长。清理回调与消息处理在同一事件循环内执行，插件关闭时移除任务并清空记录。
- 记录仅保存在内存中，最多保留 512 条，满额时淘汰最早的记录。进程重启或崩溃会丢失待选记录及已接收但未完成的请求，不恢复选择、不自动补发；重启后只回复数字不会触发解析，需要重新分享视频链接。视频下载或发送失败仍按下方规则降级，重发时也重新分享链接选择。

## 配置

在 **Web Admin → 群组 / 好友 → B 站链接** 中，按群/好友单独开关，并配置解析策略（如仅解析视频、仅解析直播、仅解析动态等）。

解析默认全部关闭，并受目标的「群消息」/「好友消息」总开关控制。官方目标在首次收到消息后进入会话缓存：先在群/好友消息页启用该目标，再配置 B 站解析。官方 Bot 无需连接 OneBot，缓存中的官方目标仍可编辑；列表不完整时数字 QQ 目标保持只读，未知 OpenID 不能直接新增策略。

## 注意事项

- 插件以较低优先级监听消息，不会阻断其他功能
- 未开启解析的群/好友中发送链接不会触发
- 官方 QQ 以原生图片/视频和文字分段回复。官方群最多 5 次、C2C 最多 4 次，会优先预留一条文案预算；超出的媒体数量会在文案中提示，完整内容可查看原链接。
- 视频下载或动态截图失败会降级为封面/API 图片与文案；媒体转存失败继续尝试剩余内容，权限、关系、过期等拒绝停止发送。若平台不允许 URL，共享发送层会移除链接后重试。
- 临时视频在发送结束或任务取消后清理，取消混流会终止 ffmpeg。
