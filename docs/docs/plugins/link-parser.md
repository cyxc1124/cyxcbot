# B 站链接解析

自动识别群聊/好友中的 **B 站** 链接并回复解析结果。对应插件：`bilibili_link_parser`。

其它平台见 [抖音链接解析](./douyin-link-parser)、[X 链接解析](./x-link-parser)。

## 触发方式

无需命令，发送含以下内容的普通消息即可触发：

- BV 号视频链接
- 直播间链接
- `b23.tv` 短链
- B 站 QQ 小程序分享

OneBot V11 的群聊/好友消息和官方 QQ Bot 的官方群/C2C 均支持。官方群需 @ 机器人，C2C 直接发送；小程序分享只在适配器实际提供 JSON/XML 消息段时提取。

## 回复内容

根据链接类型返回：

- **视频**：封面、标题、UP 主、发布时间、链接
- **直播**：封面、主播名、直播状态、链接
- **动态**：封面（首图）、作者、发布时间、链接（`opus` / `t.bilibili.com`）

## 配置

在 **Web Admin → 群组 / 好友 → B 站链接** 中，按群/好友单独开关，并配置解析策略（如仅解析视频、仅解析直播、仅解析动态等）。

解析默认全部关闭，并受目标的「群消息」/「好友消息」总开关控制。官方目标在首次收到消息后进入会话缓存：先在群/好友消息页启用该目标，再配置 B 站解析。官方 Bot 无需连接 OneBot，缓存中的官方目标仍可编辑；列表不完整时数字 QQ 目标保持只读，未知 OpenID 不能直接新增策略。

## 注意事项

- 插件以较低优先级监听消息，不会阻断其他功能
- 未开启解析的群/好友中发送链接不会触发
- 官方 QQ 以原生图片/视频和文字分段回复。官方群最多 5 次、C2C 最多 4 次，会优先预留一条文案预算；超出的媒体数量会在文案中提示，完整内容可查看原链接。
- 视频下载或动态截图失败会降级为封面/API 图片与文案；媒体转存失败继续尝试剩余内容，权限、关系、过期等拒绝停止发送。若平台不允许 URL，共享发送层会移除链接后重试。
- 临时视频在发送结束或任务取消后清理，取消混流会终止 ffmpeg。
