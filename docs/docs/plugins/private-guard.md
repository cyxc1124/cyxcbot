# 私聊守卫

控制机器人是否处理某个好友的私聊消息，同时作用于 OneBot 好友和官方 QQ 私聊（C2C）。

## 配置

在 **Web Admin → 会话 → 好友** 的「好友消息」标签中，逐个打开「处理好友消息」。

- **默认只处理已开启的好友**：新部署时所有好友都未开启，需要逐个打开。
- 打开列表中的全部好友后，切换为「全部启用」，之后的新好友也会直接处理；在全部启用时关闭任意一个好友，会回到只处理已开启好友的模式。
- 关闭后，机器人在该好友私聊中不处理命令与插件逻辑。

## 官方 QQ 私聊

官方用户在机器人收到其私聊后出现在列表中，显示带「官方」标记的 OpenID。未开启时，机器人忽略该私聊，并在日志中提示「官方用户 … 未启用好友消息，已忽略」；刷新好友页并打开该用户后，再发送私聊即可。

## 使用场景

- 限制机器人仅响应特定好友的私聊
- 配合链接解析、状态查询、[Rust RCON 远控](./rust-rcon)（私聊）等策略使用（守卫关闭时上述入站功能均不可用）

## 注意事项

与群消息守卫相同，关闭好友消息处理不影响机器人主动向该好友推送监控通知。
