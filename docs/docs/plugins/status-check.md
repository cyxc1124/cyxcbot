# 状态查询

允许特定 QQ 号查询机器人运行状态。

:::info 2.0 配置方式
允许查询的 QQ 在 **Web Admin → 系统 → 权限**（超级用户 / 专用白名单）及 **群组/好友** 策略中配置，不再使用 `STATUS_CHECK_*` 或 `SUPERUSERS` 环境变量。
:::

## 命令

| 命令 | 别名 |
|------|------|
| `/status` | `/状态`、`/运行状态` |

## 显示信息

- 机器人运行状态
- 运行时间
- 系统信息
- 内存使用情况
- Python / NoneBot 版本
- 连接状态

**状态回复内容**（详细技术信息 / 运行时长 / 内存使用情况）在 **群组 → 状态查询** 或 **好友 → 状态查询** Tab 中按会话配置，不在「系统 → 权限」。

## 权限控制

- 只响应有权限的用户，无权限用户发送命令时机器人**完全不会回复**
- 超级用户（Web Admin → **系统 → 权限**）默认可查询
- **系统 → 权限** 还可配置状态查询专用 QQ 白名单（任意会话可触发）
- 更细的按群 / 好友开关在 **群组 / 好友 → 状态查询**
- 官方 QQ Bot 的群和 C2C 会话通过收到消息发现；先在「群消息 / 好友消息」启用该会话，再配置状态查询。未连接 OneBot 或 OneBot 列表获取失败时，白名单模式下仍可单独修改已发现的官方会话，其他白名单与全部启用模式保持不变；回复内容仍可调整。
- 所有查询与无权限尝试均记录日志

## 依赖

使用 `psutil` 获取系统信息，已包含在 `requirements.txt` 中。
