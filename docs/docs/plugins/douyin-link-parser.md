# 抖音链接解析

自动识别群聊 / 私聊中的抖音分享链接，下载无水印视频、图集或 Live 图，并以 QQ 消息回传。对应插件：`douyin_link_parser`。

## 触发方式

无需命令。在已开启策略的群或好友会话中，发送含抖音链接的普通消息即可，例如：

- `v.douyin.com` 短链
- `www.douyin.com/video/...`、`www.douyin.com/note/...`
- 其它常见抖音分享 URL（会尽量规范化为 `/video/{id}` 或 `/note/{id}`）

插件以较低优先级监听消息（`priority=4, block=False`），与 [B 站链接解析](./link-parser) 同级，互不阻断。

## 支持内容

| 类型 | 说明 |
|------|------|
| 视频 | 无水印视频段回传 |
| 图集 | 静态图以图片段回传；张数过多时**按批发送**（每条最多 10 张），避免协议端发送失败 |
| Live 图 | 取动态图对应视频地址，以**视频段**发送 |

含视频时会**拆开发送**（先媒体、后文案）：QQ 同条混排 `video` 时常吞掉文字。

## 配置

默认**关闭**。需在 Web Admin 中按会话开启，并建议配置抖音账号：

| 位置 | 说明 |
|------|------|
| **群组 → 抖音链接** | 按群开关 |
| **好友 → 抖音链接** | 按好友开关 |
| **设置 → 抖音 → 账号** | 扫码登录（Playwright）或粘贴 Cookie；与 B 站账号相互独立 |
| **抖音 → 消息模板** | `link_template_douyin` |

Cookie **非硬性必填**：未配置时仍会尝试游客态解析（日志中有提示）。建议配置登录态（如含 `ttwid` / `odin_tt` / `passport_csrf_token`）；`msToken` 可缺省并由程序自动生成。

扫码登录依赖本机 / 镜像内已安装的 Chromium（见 [本地开发](../getting-started/local-dev)）。

## 消息模板

在 **抖音 → 消息模板** 中编辑 `link_template_douyin`，可用占位符：

| 占位符 | 说明 |
|--------|------|
| `{video}` | 展开为全部图片 / 视频段 |
| `{title}` | 作品标题 |
| `{author}` | 作者 |
| `{url}` | 规范分享链接 |
| `{aweme_id}` | 作品 ID |

默认模板大致为：`{video}标题：{title}\n作者：{author}\n链接：{url}`。

## 注意事项

- 须同时满足：群/好友**消息守卫**开启，且该会话的**抖音链接**策略开启
- 大图集会拆成多条消息；发送失败时请查看 `/logs` 或磁盘日志中的协议端返回
- 部分协议端 `message_id` 可能为负数，本插件将其视为发送成功（与 LuckyLilliaBot / LLOneBot 行为对齐）
