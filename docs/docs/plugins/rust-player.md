# Rust 群积分与商城

群内签到、SteamID 绑定、积分查询与积分商城兑换。对应插件：`rust_player`（**仅群聊**）。

RCON 任意远控命令见 [Rust RCON 远控](./rust-rcon)。两者共用「Rust 远控」总开关，配置入口均为 **Web Admin → Rust 群管**。

## 前置条件

1. 群消息守卫已开启
2. **Rust 群管 → 群权限** 中对该群开启 **Rust 远控**（默认关闭）
3. 兑换物品、在线签到加成等需可用的 RCON 服务器绑定（见远控文档）

群管命令触发词在 **Rust 群管 → 群管命令** 中配置（与 **设置 → 命令** 分离）。

## 命令

默认触发词如下（可自定义或禁用）。群聊中需 **@机器人**；也支持配置的命令前缀（如 `/`、`!` 等）。

| 功能 | 默认触发词 | 示例 |
|------|------------|------|
| SteamID 绑定 | `绑定` | `@机器人 绑定 7656119xxxxxxxxxx` |
| 群签到 | `签到` | `@机器人 签到` |
| 积分查询 | `我的积分`、`积分` | `@机器人 积分` |
| 商品列表 | `商品列表` | `@机器人 商品列表`、`@机器人 商品列表2`（翻页） |
| 商品兑换 | `兑换商品` | `@机器人 兑换商品 wood 5` 或 `@机器人 兑换商品 木头` |

## SteamID 绑定

- 格式：SteamID64（`7656119` 开头共 17 位数字）
- **不可自助换绑**；需更换时由管理员在面板解除绑定
- 同一 SteamID 不可被多人绑定
- **首次绑定奖励**：默认 200 积分（按 QQ + SteamID 各仅发放一次，可在面板调整）

## 签到

- 每日一次（时区 `Asia/Shanghai`）
- **基础积分**：随机区间，默认 1–10（面板可改）
- **在线加成**：已绑定 SteamID、配置了 RCON 服务器且加成 > 0 时，通过 RCON `status` 判断是否在线
  - 在线签到：基础分 + 在线加成（默认 50）
  - 离线签到后可再次 `@机器人 签到` **补领**在线加成
- RCON 不可用时会给出明确提示；在线状态有短时进程内缓存

积分按**群**独立统计。

## 积分商城

在 **Rust 群管 → 积分商城** 维护商品（中文名、物品 ID、所需积分、排序、启用）。

- 列表每页最多 20 条
- 兑换前须完成 SteamID 绑定
- 成功后通过 RCON 执行 `giveto {SteamID} {item_id} {数量}`
- RCON 认证失败时通常会退回积分；连接异常或 `giveto` 被拒时的文案与是否退分依场景而定（详见日志）

签到 / 商城使用的 RCON 服务器在 **积分与绑定 → RCON 服务器** 中选择（`0` 表示使用首个启用的绑定）。

## 管理（Web Admin）

| Tab | 说明 |
|-----|------|
| 群管命令 | 上述 5 条命令的触发词 |
| 积分与绑定 | 签到区间、在线加成、首次绑定奖励、RCON 服务器；查看/修改积分、解除 Steam 绑定 |
| 积分商城 | 商品 CRUD |

## 注意事项

- 本插件**不受** RCON 绑定「允许执行的 QQ 号」白名单限制（任意群成员在开启远控的群内可签到 / 兑换）
- 回复文案为插件内置，**不在**「消息模板」页配置
- 无专用环境变量；全部走数据库 / Web Admin
