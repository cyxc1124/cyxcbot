# 群头衔设置

群成员通过命令设置自己的 QQ 专属头衔。对应插件：`group_special_title`。

## 使用方法

须带命令前缀（默认 `/`，另可加习惯性前缀如 `#`）：

```text
/头衔 我的头衔
#头衔 我的头衔
```

- 触发词默认「头衔」，可在 **设置 → 命令** 中自定义或关闭
- 头衔最多 **6** 个字（QQ 限制）
- **设置成功或失败均不在群内回复**，仅写日志

## 前置条件

须同时满足：

1. **群组 → 群消息**：开启处理群消息（[群消息守卫](./group-guard)）
2. **群组 → 群头衔**：将该群加入白名单（默认关闭，与状态查询类似）
3. 机器人为该群**群主**（协议端 `set_group_special_title` 通常仅群主可用；管理员不够）

## 配置

| 位置 | 说明 |
|------|------|
| **群组 → 群头衔** | 按群启用；每人每群每日设置次数上限（默认 10，`0` 表示不限制；按 `Asia/Shanghai` 自然日计） |
| **设置 → 命令** | 触发词与开关；「群头衔设置」**必须带前缀**（不能仅靠裸触发词或仅 @） |

前缀来自环境变量 `COMMAND_START`（改需重启）与「习惯性前缀」（改后立即生效）。详见 [页面说明](../web-admin/pages) 中的「设置 → 命令」。

## 注意事项

- 消息中的 `@` 显示名（含 emoji）可保留；QQ 表情贴纸段无法转为文字
- 不占用消息模板；无专用环境变量
