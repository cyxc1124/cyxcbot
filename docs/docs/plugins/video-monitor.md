# 视频查询

在已配置 UP 主映射的群中，响应命令查询 UP 主最新投稿视频。

:::info 与动态监控的关系
- **自动推送**：UP 主发布新视频时，由**动态监控**检测 `DYNAMIC_TYPE_AV` 类型动态并推送
- **本插件**：仅在群内响应 `最新视频` / `最新投稿` 命令，主动拉取最新投稿列表
:::

:::info 2.0 配置方式
与动态监控共用 UP 主 → 群映射，在 **Web Admin → B 站 → 动态订阅** 中配置。B 站账号在 **B 站 → 账号** 中配置。
:::

## 命令

在已配置 UP 主映射的群中发送（支持裸命令、`@机器人` 或已配置的命令前缀；官方 QQ 群需 @ 机器人）：

| 命令 | 说明 |
|------|------|
| `最新视频` | 查询该群配置 UP 主的最新投稿 |
| `最新投稿` | 同上 |

命令前缀来自启动配置 `COMMAND_START` 和 Web Admin → **系统 → 命令** 中设置的额外前缀。默认启动前缀是 `/`；若改为 `COMMAND_START=["#"]`，可发送 `#最新视频`，而 `/最新视频` 仅在 `/` 仍属于启动前缀或额外前缀时生效。触发词本身也可在 Web Admin 的命令设置中修改。

若群未配置任何 UP 主映射，命令不会触发回复。

## 回复格式

返回各 UP 主最新一条投稿的封面、标题与链接，首行形如 `【UP主名 最新投稿】`。

支持 OneBot 与官方 QQ 群。官方查询先汇总各 UP 主的标题、链接及失败提示，再按本条消息剩余回复次数发送封面；摘要过长时分段，超过回复容量的结果会明确提示未展示。

## 注意事项

- 需配置 B 站账号以提高 API 成功率
- 仅支持群聊；私聊不响应
- 与动态监控共用映射，删除 UP 主映射后命令亦不可用
