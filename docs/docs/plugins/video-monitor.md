# 视频查询

在已配置 UP 主映射的群中，响应命令查询 UP 主最新投稿视频。

:::info 与动态监控的关系
- **自动推送**：UP 主发布新视频时，由**动态监控**检测 `DYNAMIC_TYPE_AV` 类型动态并推送
- **本插件**：仅在群内响应 `最新视频` / `最新投稿` 命令，主动拉取最新投稿列表
:::

:::info 2.0 配置方式
与动态监控共用 UP 主 → 群映射，在 **Web Admin → 动态监控** 中配置。B 站账号在 **设置 → B 站账号** 中配置。
:::

## 命令

在已配置 UP 主映射的群中发送（支持 `@机器人` 或 `/`、`!` 等前缀）：

| 命令 | 说明 |
|------|------|
| `最新视频` | 查询该群配置 UP 主的最新投稿 |
| `最新投稿` | 同上 |

若群未配置任何 UP 主映射，命令不会触发回复。

## 回复格式

返回 UP 主最近若干条投稿的标题与链接，首行形如 `【UP主名 最新投稿】`。

## 注意事项

- 需配置 B 站账号以提高 API 成功率
- 仅支持群聊；私聊不响应
- 与动态监控共用映射，删除 UP 主映射后命令亦不可用
