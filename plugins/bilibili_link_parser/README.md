# B 站链接解析

自动识别群聊/好友中的 B 站链接并回复解析结果（视频、直播、短链、QQ 小程序分享）。

> **2.0 配置**：在 Web Admin → **群组** / **好友** 中按目标开关链接解析，可分别启用视频/直播/动态解析。
>
> 完整文档：[链接解析](https://cyxc1124.github.io/cyxcbot/docs/plugins/link-parser)

## 触发方式

无需命令，发送含 BV 号、直播间链接、`b23.tv` 短链或 B 站 QQ 小程序分享的普通消息即可。

支持 OneBot V11 与官方 QQ Bot。官方群需 @ 机器人，官方 C2C 直接发送链接；小程序/JSON/XML 分享按适配器实际收到的消息内容提取。

官方会话首次收到消息后进入群/好友缓存。在 Web Admin 先启用该目标的「群消息」/「好友消息」，再开启 B 站解析（默认全关）。官方目标不要求连接 OneBot；缓存中的官方目标可以单独编辑，但不会把官方缓存当成完整 OneBot 列表，列表不完整时数字 QQ 目标保持只读。

官方回复使用原生图片/视频上传；官方群最多 5 次、C2C 最多 4 次，会为文案保留一条，并提示超出预算的媒体数量。下载、截图或媒体转存失败时尽量发送剩余封面/文案；权限、关系或过期拒绝停止本次发送，URL 拒绝由共享发送层去掉链接后重试。发送结束或取消后清理下载视频；取消混流会终止并等待 ffmpeg。
