# AI 图片检测

OneBot V11 群聊或私聊中，引用一条只包含一张图片的消息，回复 `ai吗？`。支持 `AI吗?`、`ai吗`，不需要命令前缀，沿用群聊 / 私聊消息守卫。

机器人会引用原始图片消息返回检测结果；检测失败或繁忙提示也引用同一条原消息。未引用消息时，操作提示引用用户发送的命令消息。

- 本地通过 c2pa-python 读取嵌入式 C2PA，并校验签名和图片绑定；区分凭证存在、AI 声明、来源信任和校验失败。
- Web Admin → 系统 → 高级配置保存 OpenAI API Key 后，原图还会上传固定的官方 Content Provenance API，一次获得 C2PA 和 SynthID 结果。密钥加密保存，不在设置响应或日志中返回。
- OpenAI 请求复用 Web Admin → X → 账号与代理的 HTTP/HTTPS/SOCKS5 出站配置，保存后立即生效；关闭该配置时仍遵循运行环境代理。QQ 图片下载与本地 C2PA 不使用这项代理。
- 未配置密钥时仍执行本地检查，明确报告外部检测未完成；外部调用失败也保留本地结果，不把错误当作未检出。
- OpenAI 接口仅验证其支持的 OpenAI 来源信号，不是通用 AI 图片分类器。没有信号时回复“无法判断”，不判定为真人创作。
- 支持 PNG / JPEG / WebP / GIF，单图最多 20 MiB、2500 万像素。仅下载 QQ 图片 CDN，包括 NapCat 等协议端使用的 `multimedia.nt.qq.com.cn`；禁止跳转和本地文件路径，不重新编码或持久化图片。
- 一个进程同时处理一条检测请求；繁忙时直接提示重试。外部请求不自动重试，不进行批量识别。
- 官方 QQ Bot 的引用图片未接入；本次只支持现有 OneBot 引用消息机制。

入口在 `__init__.py`；下载、C2PA、OpenAI 接口和回复分别位于同目录模块。配置复用 SystemSetting，无需修改表结构。

完整使用说明、限制与其他服务价格调研见 [文档站页面](../../docs/docs/plugins/ai-image-detector.md)。
