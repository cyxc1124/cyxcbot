# UP 主动态监控

监控 B 站 UP 主动态更新，向配置的群/好友推送通知；支持主动查询与动态图片提取。

> **2.0 配置**：在 Web Admin → **动态监控** 与 **设置 → 监控参数** 中管理 UP 主映射、间隔、截图开关等，不再使用 `DYNAMIC_MONITOR_*` 环境变量。
>
> 完整文档：[动态监控](https://cyxc1124.github.io/cyxcbot/docs/plugins/dynamic-monitor)

## 命令

在已配置 UP 主映射的群中：

| 命令 | 说明 |
|------|------|
| `最新动态` | 主动查询 UP 主最新动态 |
| `置顶动态` | 主动查询 UP 主置顶动态 |
| `/提取 <动态ID>` / `/获取 <动态ID>` | 按动态 ID 拉取图片（群聊/私聊） |
| 引用机器人动态消息后发送 `/提取` / `/获取` | 从引用消息的动态链接识别目标并拉取图片（OneBot 群聊/私聊） |

引用提取沿用订阅限制、命令开关、自定义触发词与前缀；仅接受当前机器人发出的消息，且原文需包含唯一的动态链接（`t.bilibili.com` 或 `bilibili.com/opus/`）。自定义动态模板应保留 `{url}`；原文缺失或目标不明确时，会提示手动填写动态 ID。显式填写的动态 ID 或链接优先于引用内容。

> 触发词可在 Web Admin → **设置 → 命令** 中自定义（含开关与恢复默认），保存后立即生效。前缀取决于部署的 `COMMAND_START`（默认 `/`，改需重启），另加「习惯性前缀」（默认 `!`/`。`/`.`/`#`，可在同一页面自定义，改后立即生效）。

## 文件结构

```
plugins/dynamic_monitor/
├── __init__.py          # 插件入口、生命周期、查询命令
├── config.py            # 从 ConfigService 加载配置
├── dynamic_monitor.py   # 轮询监控核心逻辑
├── dynamic_extract.py   # 动态图片提取
├── sender.py            # 消息构建与发送
└── README.md
```

B 站 API 封装见 `utils/bilibili_api/`；截图见 `utils/screenshot/`。

## 图片模式

设置 → B 站 → 监控参数可选择网页截图（默认）或莫奈卡片。卡片直接绘制 API 内容，以配图/头像提取 HCT 主题色，背景由深到浅；最多 6000 字、100 行、9 张图，完整内容见二维码。模式支持热重载并应用于推送和查询，失败时发送文字与原图。卡片渲染入口：`utils/dynamic_card.py`。

莫奈卡片的「卡片取色来源」可选择 **动态配图（默认）** 或 **作者头像**，保存后热重载。配图模式取第一张配图，无配图则用头像；头像模式始终取作者头像。所选取色素材不可用时使用默认紫色。此设置只影响卡片配色，不改变卡片展示的头像与配图。
