# 机器人状态查询

允许特定 QQ 号查询机器人运行状态（运行时间、系统信息、内存、连接状态等）。

> **2.0 配置**：在 Web Admin → **设置 → 机器人** 配置超级用户与专用白名单；在 **群组** / **好友** 页面按目标开关状态查询策略。不再使用 `STATUS_CHECK_*` 或 `SUPERUSERS` 环境变量。
>
> 完整文档：[状态查询](https://cyxc1124.github.io/cyxcbot/docs/plugins/status-check)

## 命令

| 命令 | 别名 |
|------|------|
| `/status` | `/状态`、`/运行状态` |

> 触发词可在 Web Admin → **设置 → 命令** 中自定义（含开关与恢复默认），保存后立即生效。

## 权限

- 超级用户、专用白名单 QQ、或已在群/好友策略中开启状态查询的用户可触发
- 无权限用户发送命令时机器人**完全不会回复**
- 显示项（详细状态、运行时间、内存）在 Web Admin 设置中配置

## 依赖

`psutil`（已包含在根目录 `requirements.txt`）。
